# ✝️ Ministerio Caminos de Fe — Altar de Montaña, Cultos y Discipulado en Traslasierra

Plataforma institucional de alta fidelidad, Scrollytelling interactivo en Canvas (240 fotogramas con inercia Lerp a 60 FPS), Muro de Oración, Asistente de IA (Luz-04) y Búnker Pastoral & Técnico.

## 🏛️ Ecosistema Faro de Luz (SNC 2.0)
- **Motor Financiero & Tecnológico:** ShopDigital (Luz-01)
- **Base Ecotecnológica de Montaña:** Comunidad Faro de Luz (Luz-02)
- **Acción & Asistencia Social:** Fundación Valle de Luz (Luz-03)
- **Altar Espiritual & Legalidad:** Ministerio Caminos de Fe (Luz-04)

## 🚀 Puesta en Marcha Local
```bash
npm install
npm start
# Acceso en http://localhost:3000
```
