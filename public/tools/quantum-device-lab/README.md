## 🌟 ¿Qué es Quantum Device Lab?
**Quantum Device Lab** es una herramienta de ingeniería visual web ligera, ultra-rápida y de código abierto, diseñada para auditar e inspeccionar cómo se ven sitios web en múltiples resoluciones reales de forma simultánea.

Nació de una necesidad real en el desarrollo de **Ministerio Caminos de Fe**, **Fundación Valle de Luz** y **ShopDigital**: verificar instantáneamente cómo impactan los cambios en celulares angostos (*TCL, Motorola E* de 360px), smartphones modernos (*Motorola G, iPhone, Samsung* de 393px a 412px) y computadoras de escritorio, evitando que botones importantes como Donaciones o Streaming queden ocultos.

---

## 🚀 Características Principales
* 📱 **Presets de Hardware Reales:**
  * **TCL 40 / Moto E22:** 360px × 640px (pantalla estrecha)
  * **Motorola G54 / iPhone 15:** 393px × 852px (estándar global)
  * **Samsung Galaxy S24 / Pixel:** 412px × 915px (Android amplio)
  * **iPad / Tablets:** 768px × 1024px
  * **Desktop / Laptops:** 1280px × 800px
* 📊 **Matriz Comparativa Triple:** Permite ver los 3 tamaños clave lado a lado con iframes sincronizados.
* 🛡️ **Auditor de Desbordamiento (Overflow Scanner):** Diagnóstico en vivo para detectar si algún elemento genera scroll horizontal invisible o rompe el layout en móviles.
* 🔄 **Controles de Giro:** Alterná entre modo vertical (Portrait) y horizontal (Landscape) con 1 clic.
* ⚡ **Cero Dependencias Pesadas:** Construido con HTML5, Tailwind CSS y JavaScript vanilla, liviano como una pluma y compatible con cualquier navegador.

## 🛠️ Cómo Usarlo en tu Proyecto
1. Clona este repositorio:
```bash
git clone https://github.com/tu-usuario/quantum-device-lab.git
```
2. Abrí `index.html` directamente en tu navegador o servilo con cualquier servidor web (Node, Python, Vercel, Vite):
```bash
npx serve .
```
3. Escribí cualquier URL en la barra de direcciones y probá tu diseño en vivo.
